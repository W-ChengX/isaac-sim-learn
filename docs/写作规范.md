# 写作规范

本页约定本仓库（及站点）笔记怎么写，保证章节可验收、可对照官方、不踩许可与资产红线。

## 章节模板（固定顺序）

每章正文尽量按下列块组织；标题可微调，但**顺序与信息密度**保持一致：

1. **学习目标** — 读完本章你要会什么（可观测、可复述）。
2. **你将完成什么（验收清单）** — 勾选项；默认假设主路径 **5.1.0**。
3. **概念讲解（自己的话）** — 用中文讲清楚「为什么 / 是什么」；专名保留英文便于搜官方。
4. **推荐步骤（链官方）** — 只写步骤骨架与**官方绝对 URL**；细节以打开的官方页为准，不抄长文。
5. **5.1 vs 6.x 差异要点** — 对照轨短记；未验证的差异标成「待对照」。
6. **常见坑** — 本机高频翻车点；与「概念」分开，方便速查。
7. **延伸阅读 / 官方对照** — 同时给出 **5.1.0** 与 **latest / 6.0.x** 入口。

可选：章内短「中英术语」表；全局术语归 [术语表.md](术语表.md)。

## 版权与引用

- **禁止**整章翻译或大段复述 NVIDIA 官方文档；本仓库写骨架、验收与坑，细节链回官方。
- 官方链接一律用**绝对 URL**，并尽量同时给出：
  - 主路径：`https://docs.isaacsim.omniverse.nvidia.com/5.1.0/...`
  - 对照 / 最新：`https://docs.isaacsim.omniverse.nvidia.com/latest/...`（或具体 6.0.x 页）
- 引用社区文章时标明「非官方」，且仍以官方页为验收依据。

## No-assets 政策

- **禁止**提交 NVIDIA 官方 USD / 贴图 / 模型 / Assets Pack / 安装器（含 Git LFS）。
- 示例只写本机路径文字，例如：`# asset: <ISAAC_SIM>/...`。
- 自有脚本可放 [examples/](../examples/)；仍不得夹带官方资产。详见 [LICENSE-NOTES.md](LICENSE-NOTES.md)。

## 双轨版本钉死

| 轨道 | 版本 | 写作约定 |
|------|------|----------|
| 主路径 | **5.1.0** | 验收清单、默认步骤、截图描述均按它 |
| 对照 | **6.0.1 / latest** | 单独成段或成章；不默认插入主路径顺序 |

- 同一段步骤里不要混写两个大版本的菜单路径。
- 根目录 [VERSIONS.md](../VERSIONS.md) 仅为指针；正文权威在本目录 [VERSIONS.md](VERSIONS.md)。

## 何时拆成多页

单章 `index.md` 变长时，再拆子页（本轮不强制物理搬家）：

- 出现**两套以上独立验收清单**（例如「GUI 入门」与「Standalone 入门」）。
- 对照轨内容超过主路径一半篇幅 → 迁到「对照与升级」或章内 `diff.md`。
- 速查表 / 命令清单反复被其它章引用 → 抽到 [速查表](速查表/index.md) 或独立附录。
- 拆页后：父 `index.md` 保留导读 + 链接；导航在 `mkdocs.yml` 对应分组下追加子项。

## 语气与格式

- 中文为主，专名保留英文；语气直接、可操作，少空话。
- 表格优先于长段落枚举；警告用简短列表即可。
- 不在正文承诺「保证兼容某第三方 fork」；版本以官方文档为准。
