# 术语表

短定义便于中文阅读；英文专名保留，便于对照官方文档与 API。可选「中英对照」见各章；此处为全局速查。

| 中文常用说法 | English | 简短说明 |
|--------------|---------|----------|
| Isaac Sim | Isaac Sim | NVIDIA 面向机器人仿真与合成数据的应用；基于 Omniverse / Kit 构建。本仓库主路径 **5.1.0**。 |
| Omniverse Kit | Omniverse Kit | 应用与扩展的运行时框架；Isaac Sim 是其上的机器人向产品。 |
| USD / OpenUSD | USD / OpenUSD | 通用场景描述：层级、引用、属性、时间采样等；Isaac 场景几乎都以 USD 表达。 |
| Stage（舞台/阶段） | Stage | 当前打开的 USD 场景图容器；GUI 里看到的世界状态主要挂在 Stage 上。 |
| Prim（图元） | Prim | Stage 上的节点（物体、灯光、Xform 等）；路径形如 `/World/Cube`。 |
| Layer（层） | Layer | USD 意见（opinion）的容器；组合多个 layer 形成最终 Stage 视图。 |
| Reference / Payload | Reference / Payload | 引用外部 USD；payload 可延迟加载，避免一打开就吃满内存。 |
| Articulation（关节机构） | Articulation | 带关节约束的刚体树（机械臂、移动底盘等）；控制时常对 articulation root 发命令。 |
| Extension（扩展） | Extension | Kit 的可插拔模块（启用/禁用）；GUI 功能与许多 Isaac 能力以扩展形式存在。 |
| GUI 工作流 | GUI workflow | 在 Isaac Sim 窗口里点选、拖资产、改属性、点 Play。 |
| Extension 脚本工作流 | Extension scripting | 在已启动的应用内用扩展 / Script Editor 跑代码，共享同一 Stage。 |
| Standalone（独立脚本） | Standalone | 从终端启动 Python，自行创建 `SimulationApp`，适合批处理与 CI。 |
| SimulationApp | SimulationApp | Standalone 入口：拉起 Kit 运行时、配置头显/无头模式、生命周期管理。 |
| PhysX | PhysX | 经典刚体 / 关节物理后端之一；大量教程仍围绕 PhysX 属性与碰撞。 |
| Newton | Newton | 较新物理栈方向（6.x 文档会更多提及）；对照轨阅读时注意后端切换说明。 |
| Nucleus | Nucleus | Omniverse 资产/协作服务；学习阶段也可用本地安装目录中的示例路径。 |
| Assets Pack | Assets Pack | 官方示例与机器人等资源包；**本仓库不提交这些文件**，仅在本机按官方指引使用。 |
| ROS2 Bridge | ROS2 Bridge | 把仿真话题/服务桥到 ROS 2；版本与发行版（Humble / Jazzy 等）需与文档匹配。 |
| SDG | Synthetic Data Generation | 合成数据生成：域随机化、传感器渲染、标注导出等。 |
| Isaac Lab | Isaac Lab | 基于 Isaac Sim 的机器人学习 / RL 框架（独立仓库与文档）。 |
| Compatibility Checker | Compatibility Checker | 官方兼容性检查工具：装前核对 GPU、驱动、OS 等是否达标。 |
| Launcher（已弃用） | Omniverse Launcher | 旧安装入口；自 **2025-10-01** 起弃用，请改用当前文档的 zip / pip / Docker 等通道。 |
| 工作站安装 | Workstation install | 本机解压或安装后直接跑 GUI；适合日常开发。 |
| 容器安装 | Container install | Docker 等容器方式；适合服务器与复现环境。 |
| pip / Python 包安装 | pip install | 经官方文档说明的 Python 包方式；注意与主程序版本、Python 小版本对齐。 |
| 刚体 | Rigid Body | 参与物理积分的实体；需配合碰撞形状才「撞得上」。 |
| 碰撞体 | Collider | 碰撞几何（凸包、三角网格等）；与可视 mesh 可以不是同一套。 |
| 驱动 / 关节命令 | Drive / Joint command | 对关节发位置、速度或力矩类目标；具体 API 随工作流与版本变化。 |
| Shim（过渡层） | Shim / compatibility shim | 旧 API 名到新 API 的临时兼容层；6.x 迁移中会逐步移除，勿长期依赖。 |
| 着色器缓存 | Shader cache | 首次启动编译着色器会很慢；属正常现象，第二次会快很多。 |
