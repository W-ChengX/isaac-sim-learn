# 08 SDG 与传感器

## 学习目标

- 了解合成数据生成（SDG）与常用传感器（相机、LiDAR 等）入口。
- 能在本机打开官方传感器 / SDG 示例并记录参数。
- 输出数据留在本地，不入库。
