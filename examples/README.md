# examples/

占位目录：**请在本地已安装 Isaac Sim 后再运行脚本**。

## 约定

- 本目录只放你自己写的小型脚本 / 说明，**不放 NVIDIA 官方 USD / 贴图 / 模型**。
- 需要官方资产时，在注释里写本机安装路径，例如：`# asset: <ISAAC_SIM>/...`。
- 主路径默认假设 **Isaac Sim 5.1.0**；若脚本针对 6.0.1，文件名或注释标明版本。
